# Contribution Policies

Thank you very much for having an interest to contribute to this repository.

We welcome your contributions.

To keep this repository for another contributor easy to join, please comply these policies on this repository.

## Code of Conduct

Please read the [Code of Conduct](./CODE_OF_CONDUCT.md) carefully.
This is an important code you have to remember.

## Issues and Discussions

Please feel free to join our community via issues.
Your report on the issues page helps our improvement of this application.

### When to Make a New Issue

You should not make a new issue basically.
However, you should do when the following conditions are fulfilled:

1. There is no open issue related to your problem *or*
2. Both of these are fulfilled *or*
   1. There is an open issue related to your problem *and*
   2. The issue is connected to a pull request
3. Both of these are fullfiled
   1. There is an open issue related to your plan of fixing *and*
   2. Your plan fixes the problem partially

### Discussions

If you have an idea to discuss but not cuncrete, please feel free to join our discussions or create one.

## How to Contribute to This Repository

Please **fork** this repository first.
No direct commit to this repository is allowed other than the collaborators.

### Step 1: Fork

Please fork this repository's `master` branch.

### Step 2: Make a Work Branch

Please make a work branch to modify the source codes.
The branch name must follow the following format:

```text
[type]/[summary-of-planned-pull-request]
```

The `[type]` follows the ones of [Conventional Commits](https://www.conventionalcommits.org/)

### Step 3: Making Changes

Please follow the rules of [Conventional Commits](https://www.conventionalcommits.org/) when you make a commit.

### Step 4: Make a PR

Please make a pull request with filling all fields of the PR template.

Once the collaborator permitted the PR, the your contribution is reflected to the repository.
